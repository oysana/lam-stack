# Pack duel — 2026-11-08

**Question.** Given the same task, same model, same starting commit, and one skill
pack mounted per arm, does the pack change the observable result?

**Verdict so far.** Saturated instrument on the strong-model lane — **no
separation between packs, LAM does not beat any rival on this lane.** The
free-model OpenCode lane (the designed discriminator) is armed for the quota
reset; its result decides the GA gate. Numbers below are exact, all artifacts
kept under `/tmp/opencode/lam-eval/runs/`.

Every run produced a correct fix, a passing own-test, and on T3 the full
convention stack (version bump, package revision, CHANGELOG, STATUS sync, often
a full `check.sh` run). Seed-to-seed variance inside an arm (13 vs 14) is the
same size as arm-to-arm variance — the tasks are inside every pack's reach at
this model strength. This is a ceiling effect, not proof the packs are equal.
